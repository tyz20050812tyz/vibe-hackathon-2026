# AI Discovery 契约更新说明

日期：2026-08-26

## 冻结决策

- 用户画像领域统一使用 `ReadingProfile`；旧的 `ReaderProfile` 仅保留给既有个人资料语义。
- `/api/reader-profile` 使用 Bearer token；搜索的 `sort=personalized` 与 discoveries 可选 Bearer，认证失败静默回退目录排序。
- 迁移顺序固定为语言字段、阅读画像、v2 搜索 RPC。旧四参数搜索函数先撤销权限并删除，再创建新函数，避免 Supabase RPC 重载歧义。
- 阅读画像写入和清空只能经 `replace_reader_profile`、`clear_reader_profile` 原子 RPC；表 API 只读本人。
- 搜索重复键使用 `getAll`；重复值、未知参数、非法范围统一 `VALIDATION_ERROR`。清除筛选保留 `q`、`sort`、`limit`。
- Discovery Context 使用 AES-256-GCM 加密、5 分钟过期；相关响应使用私有 no-store 和 same-origin Referer 策略，日志不记录密文。
