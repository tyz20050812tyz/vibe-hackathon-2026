# 提示词模板

> 题目发布后替换所有 `[方括号]` 内容，再按小任务分别发送给 AI。

## 1. 审题与 MVP

```markdown
你是 Vibe Coding 竞赛的产品经理兼技术负责人。

赛题：[粘贴赛题]
比赛时长：[时长]
技术栈：Next.js、TypeScript、Tailwind、shadcn/ui、Supabase、Vercel。

请输出：
1. 目标用户、痛点和一句话产品定义。
2. 只能在比赛时间内完成的 P0 功能。
3. 不做清单与原因。
4. 3-5 步 Demo 动线。
5. 需要的数据实体和状态。

每项 P0 都写出验收标准。不要给泛泛功能列表。
```

## 2. 数据库与 API 契约

```markdown
你是 TypeScript 全栈架构师。

产品定义：[粘贴]
P0 功能：[粘贴]

请输出：
1. Supabase PostgreSQL 建表 SQL。
2. 每张表的 RLS 策略。
3. lib/types/api.ts 的请求、成功和失败类型。
4. API 的 method、path、请求、返回和状态码。

要求：不使用 any；service-role key 不暴露给浏览器；先保证 MVP。
```

## 3. 小范围实现

```markdown
你是 Next.js App Router + TypeScript 工程师。

任务：[具体一个功能]
相关类型：[粘贴类型]
验收标准：[成功、失败和边界情况]
现有目录约定：API 在 app/api，服务在 lib/services，共享类型在 lib/types。

请先列出要修改的文件，再给出实现。
要求：不修改无关代码；不使用 any；校验所有外部输入；给出验证命令。
```
