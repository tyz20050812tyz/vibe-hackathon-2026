## 需求概述

AI Discovery 的关系图推荐、模板降级和 DeepSeek 叙述适配器已经具备。下一步应补齐发现接口的独立滥用防护，使可选的 DeepSeek 叙述能够在不影响目录发现、打开资源或收藏的前提下进入 Preview 验收，并继续默认关闭直至验收通过。

## 功能需求

### P0 - 必须实现

- [ ] 发现接口入口限流：在解析完请求体大小、调用目录或模型依赖前，按可信代理提供的规范化 IP 和请求体字节数执行分布式限流。
- [ ] 限流响应：超过入口限额时返回 `429 RATE_LIMITED`；超过 8 KB 的请求保持返回 `400 VALIDATION_ERROR`。
- [ ] 不阻断降级：模型身份限流、并发上限、日预算、熔断或 Provider 失败时，继续返回人工关系说明，推荐、打开和收藏可正常完成。
- [ ] 可观测性与测试：记录不含 IP 原文、token、context 或画像的限流结果；补充 Route/服务测试，覆盖匿名、可信代理、未配置代理和超限场景。

### P1 - 重要功能

- [ ] Preview 验收：分别验证模板模式、模型开启后的有效输出、超时/非法输出和模型资源耗尽后的模板降级，确认候选资源不因模型状态改变。
- [ ] 发布开关：仅在 Preview 验收、密钥隔离和日志审查均通过后，才允许在目标环境启用 `DEEPSEEK_ENABLED=true`。

### P2 - 可选功能

- [ ] 反馈学习、模型文案持久化、自动推断标签和向量检索另行立项；不纳入本次模型叙述发布。

## 非功能需求

- 性能：入口限流不应增加发现主路径的明显等待；模型调用仍保持 5 秒超时。
- 安全：只信任明确配置的代理头；不记录原始 IP、Bearer token、`discoveryContext` 或解密后的筛选内容。
- 可用性：限流服务不可用时，DeepSeek 必须保持关闭或回退人工模板，不能让公共目录发现不可用。

## 边界与约束

- 不包含：让模型参与候选生成、关系排序或扩展资源目录。
- 技术限制：限流计数必须使用部署间共享的原子存储；单进程内存计数不满足要求。
- 外部依赖：Supabase 服务端控制存储、可信反向代理配置，以及 DeepSeek 服务端密钥。

## 验收标准

### 发现接口入口限流

- Given 请求来自已配置的可信代理，When 同一 IP 在窗口内超过限额，Then 接口在访问 Supabase 或 DeepSeek 前返回 `429 RATE_LIMITED`。
- Given `TRUST_PROXY` 未开启，When 请求伪造 `x-forwarded-for`，Then 该请求不能借此改变限流身份。
- Given 请求体超过 8 KB，When 调用发现接口，Then 返回 `400 VALIDATION_ERROR`，且不创建任何限流或模型尝试记录。

### 模型降级

- Given 模型未配置、模型调用失败或模型级配额耗尽，When 用户请求一条存在关系的发现推荐，Then 返回相同的目标资源和人工 `relationExplanation`，`narrationSource` 为 `template`。
- Given 模型正常输出符合结构化校验，When 发现推荐成功，Then 仅替换阅读引导文案，候选资源、关系类型与排序结果保持不变。

### Preview 发布

- Given Preview 环境完成迁移和配置，When 分别执行模型关闭、开启、超时和限额耗尽的测试故事，Then 搜索、发现、打开资源和收藏均可用，且日志不含敏感字段。
