# AI 馆长与资源星图开发计划

> 计划周期：2026-08-27 至 2026-08-31
>
> 前端负责人：佟雨泽；后端负责人：杨思涵。
>
> 本计划以现有 `resource_relations`、阅读偏好、收藏与 AI Discovery 契约为基础。任何共享类型、数据库表、Zod schema 或接口变更，都必须先更新 `docs/09-数据契约规范.md` 并经双方确认。

## 一、最终体验

```text
资源详情
  -> 资源星图：看见所有一跳关联和受控二跳扩展
  -> AI 馆长：把阅读意图组织成三步路线
  -> 今日推荐：给出熟悉、跨一步、意外发现三项资源
  -> 用户中心：沉淀浏览、收藏、笔记和阅读轨迹
```

四项能力不是四套推荐算法：星图和每日推荐都只消费目录、人工关系与用户明确同意的数据；AI 只翻译意图和写引导，不能生成目录外书目、关系或事实。

## 二、范围与核心决策

### 1. 资源星图

- 路径：`/resources/[slug]/constellation`，资源详情页提供入口。
- 中心节点是当前书、论文、讲座或专题。
- 默认展示全部直接入边和出边；“展开下一圈”最多增加 12 个二跳节点。
- 距离只表示跳数：中心 0 跳、内环 1 跳、外环 2 跳。
- 颜色只表示关系类型：`same_theme`、`contrasting_view`、`historical_context`、`unexpected_bridge`。
- 线宽和不透明度只表示既有 `strength`，箭头保留关系方向。
- 服务端返回图拓扑，前端用稳定的径向布局渲染；不将坐标、模型分数或私密数据写入数据库。
- 桌面端支持缩放、聚焦、关系筛选和解释侧栏；移动端改为节点带与底部详情抽屉，不强制拖拽画布。

### 2. AI 馆长

- 不是无限对话机器人，而是受约束的“阅读路线编辑”。
- 输入最多 200 字，用户先得到“阅读简报”，确认后才展示至多三步路线。
- 简报只可输出现有标签、语言、资源类型、发现方向和探索幅度。
- 路线只可从目录和关系图中选资源；每一步都显示人工关系解释。
- 模型关闭、超时、输出不合法或配额耗尽时，回退规则解释器，仍可生成目录内路线。
- 不保存聊天全文；喜爱书目原文、用户 ID、令牌、完整浏览 URL 和 `discoveryContext` 不发送给模型。

### 3. 每日推荐

- 登录用户每天得到三张稳定卡片：`熟悉一点`、`跨一步`、`意外发现`。
- 匿名用户使用同日编辑策展版本，不收集匿名浏览历史。
- 候选固定从公开目录产生，排除已收藏和最近 7 天已展示资源。
- 排序顺序：硬筛选与公开状态 -> 人工关系强度 -> 兴趣标签重合 -> 新颖度/去重 -> 精选兜底。
- 首次读取当天推荐时惰性生成并持久化，无需 cron；同一天刷新不换书。

### 4. 用户中心与浏览历史

- 新增“继续阅读”“今日路线”“我的轨迹”“隐私与数据”四个区域，保留现有书架与笔记。
- 浏览历史只对登录用户开放，默认关闭，用户明确同意后才记录。
- 详情页停留 8 秒后才发送一次受控浏览事件；不以滚动、鼠标轨迹或完整 URL 做埋点。
- 用户可关闭和清空历史；关闭后立即停止记录，未来推荐不再使用浏览信号。

## 三、契约变更提议

> 以下是开发前的提议，不得在双方确认前直接实现到共享类型和 migration。

```ts
type ConstellationDepth = 1 | 2;

type ConstellationNode = {
  resource: ResourceListItem;
  hop: 0 | 1 | 2;
  relationStrength: number | null;
  relationTypes: RelationType[];
  isSaved: boolean;
  affinity: number | null; // 仅视觉提示，不改变拓扑
};

type ConstellationEdge = {
  id: string;
  sourceResourceId: string;
  targetResourceId: string;
  relationType: RelationType;
  explanation: string;
  strength: number;
  direction: "outbound" | "inbound";
};

type ConstellationData = {
  centerResourceId: string;
  nodes: ConstellationNode[];
  edges: ConstellationEdge[];
  hasMoreSecondHop: boolean;
  personalization: "profile" | "catalog";
};

type LibrarianBrief = {
  recognizedTagSlugs: string[]; // 最多 3 个，均为现有标签
  types: ResourceType[];
  languages: ResourceLanguage[];
  mode: DiscoveryMode;
  explorationLevel: ExplorationLevel | null;
  clarificationNeeded: boolean;
  userFacingSummary: string;
};
```

拟新增接口：

| 接口 | 认证 | 职责 |
| --- | --- | --- |
| `GET /api/resources/[slug]/constellation?depth=1|2` | 可选 Bearer | 返回公开图拓扑；登录只影响收藏标记和视觉亲和度。 |
| `POST /api/librarian/brief` | 可选 Bearer | 将受限意图转为阅读简报与三步路线。 |
| `GET /api/daily-recommendation` | 可选 Bearer | 返回当天三张稳定推荐或匿名策展回退。 |
| `GET/DELETE /api/reading-history` | 必须登录 | 读取或清空本人历史。 |
| `POST /api/reading-history` | 必须登录且已同意 | 记录受控来源的资源浏览。 |

拟新增数据：

```text
reading_history
  user_id, resource_id                         # 联合主键
  first_viewed_at, last_viewed_at, view_count
  last_source: catalog | constellation | librarian | daily | direct

reading_history_settings
  user_id                                      # 主键
  enabled boolean default false
  consented_at, updated_at

user_daily_recommendations
  user_id, recommendation_date, slot           # 联合主键
  resource_id, reason_snapshot, source_signals
  created_at
```

三张表均开启 RLS；用户只能读写自己的记录。推荐生成采用服务端受控事务或 `SECURITY DEFINER` RPC，永不接受客户端 `userId`。星图只需增加 `resource_relations(target_resource_id, strength desc)` 索引，不新建关系表。

## 六、最终发布门禁

- [ ] 星图一跳完整、二跳有上限且无环路/重复；关系解释可追溯至人工策展数据。
- [ ] AI 馆长只使用目录与关系图；模型关闭、失败、限额时规则路线仍可用。
- [ ] 每日推荐同用户同日稳定、可解释、无匿名个人数据。
- [ ] 浏览历史默认关闭；用户只能读写自己的历史、设置和每日推荐。
- [ ] 桌面和 390px 移动端均能完成：资源详情 -> 星图 -> AI 馆长/每日推荐 -> 收藏 -> 用户中心。
- [ ] `npm test`、`npm run lint`、`npm run build`、关键 E2E 和 Preview 验收通过。

## 七、明确不做

- 无限深度知识图谱、向量检索、外网爬取和模型自动创建关系；
- 无限轮聊天、保存聊天全文、用户侧模型记忆；
- 将浏览历史默认打开，或将个人数据用于目录外目的；
- 让 AI 覆盖硬筛选、人工关系、资源事实或用户数据写入权限。
