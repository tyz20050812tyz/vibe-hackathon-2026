## 统一 API 格式

所有新接口先在 `lib/types/api.ts` 定义，再开始写两端代码。

```ts
export type ApiSuccess<T> = {
  data: T;
  requestId: string;
};

export type ApiFailure = {
  error: {
    code: string;
    message: string;
  };
  requestId: string;
};
```

每个接口必须写清楚：

- method 和 path，例如 `POST /api/analyses`。
- 请求字段、类型、是否必填。
- 成功时的 `data` 结构。
- 失败时的 `error.code` 和 `error.message`。
- 状态码：`400` 参数错误、`401` 未登录、`403` 无权限、`404` 不存在、`500` 服务异常。

前端只使用契约字段渲染页面；后端修改契约前必须通知前端。接口失败时，前端必须有加载和错误状态，不能白屏。
