# 技术栈与本地启动

> 目标：让每位队员都能在自己的电脑上跑通项目。

## 技术栈

| 领域 | 技术 |
| --- | --- |
| 前端 | Next.js App Router + React |
| 语言 | TypeScript |
| 样式 | Tailwind CSS + shadcn/ui + Lucide React |
| 后端 | Route Handlers + Server Actions |
| 数据库 | Supabase PostgreSQL |
| 部署 | Vercel |

## 目录约定

```text
app/             页面与 API
components/      UI 组件
lib/types/       前后端共用类型
lib/services/    后端业务逻辑
lib/supabase/    Supabase 客户端
docs/            团队文档
```

## 加入项目

前置条件：已安装 Node.js 20+、npm 和 Git，并拥有 GitHub 仓库权限。

```bash
git clone https://github.com/tyz20050812tyz/vibe-hackathon-2026.git
cd vibe-hackathon-2026
npm install
cp .env.example .env.local
npm run dev
```

浏览器打开 `http://localhost:3000`。

加入项目和每次合并前都运行：

```bash
npm run lint
npm run build
```

## 环境变量

`.env.local` 放真实密钥，不能提交。`.env.example` 只放变量名，可以提交。

```dotenv
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=
DISCOVERY_CONTEXT_ENCRYPTION_KEY=
DEEPSEEK_API_KEY=
DEEPSEEK_MODEL=
```

`NEXT_PUBLIC_` 开头的变量会发送到浏览器，只能放公开配置。service-role key、Discovery Context 加密密钥和 DeepSeek 配置只能在服务端使用。`DISCOVERY_CONTEXT_ENCRYPTION_KEY` 需要是 32 字节随机值的 Base64 编码，可运行 `openssl rand -base64 32` 生成。

## 注意

当前项目使用 Google Fonts 的 Geist 字体。赛前需要在可用网络和受限网络下各跑一次 `npm run build`；如果构建失败，改用本地字体或系统字体。
