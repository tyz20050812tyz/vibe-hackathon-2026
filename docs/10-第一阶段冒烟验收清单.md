# 第一阶段冒烟验收清单

> 在 Preview 或 Production 执行。通过前不要开始第二阶段的 AI 与“意外发现”功能。

## 执行前准备

1. 确认 `20260821_create_library_foundation.sql` 与 `202608210001_add_resource_catalog_search.sql` 已在目标 Supabase 项目执行。
2. 执行 [资源种子数据](../supabase/seed/resources-v1.sql)，并确认 `GET /api/resources?limit=50` 返回 20 条资源。
3. 准备两个互不相同的普通 Supabase Auth 测试账号：账号 A 与账号 B。
4. 在 Preview 或 Production 配置 `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` 和 `SUPABASE_SERVICE_ROLE_KEY`。

## 公共目录

| 步骤 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 1 | 打开 `/` | 显示精选资源和六个热门主题；点击任一主题进入带 `tag` 参数的搜索页 | [ ] |
| 2 | 搜索 `/search?q=AI` | 至少显示 3 条匹配资源；URL 保留 `q=AI` | [ ] |
| 3 | 在带关键词的搜索页点击一个主题 | `q` 与 `tag` 同时保留，结果随筛选变化 | [ ] |
| 4 | 搜索一个不存在的词 | 显示“没有找到相符的资源”，页面不白屏 | [ ] |
| 5 | 打开 `the-creative-act`、`the-image-of-the-city`、`the-library-of-babel` 的详情页 | 每页有封面、作者、摘要、标签、演示状态及位置 | [ ] |
| 6 | 在慢速网络下打开首页、搜索和资源详情 | 每页显示加载提示，且加载完成后内容正常替换 | [ ] |
| 7 | 临时断开资源 API 或访问不可用 Preview | 首页、搜索和详情显示可理解的错误或重试入口，不白屏 | [ ] |

## 个人书架

| 步骤 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 8 | 未登录时在资源详情点击收藏 | 明确引导用户前往个人书架登录，不显示“已收藏” | [ ] |
| 9 | 用账号 A 登录 `/library` | 显示空书架或仅显示账号 A 已有的收藏 | [ ] |
| 10 | 在慢速网络下打开 `/library`，并暂时使书架请求失败 | 分别显示加载提示和可理解的失败提示，不白屏 | [ ] |
| 11 | 从任意资源详情收藏 | 显示“已保存到个人书架”；书架出现该资源 | [ ] |
| 12 | 刷新详情页与 `/library`，重新登录账号 A | 收藏仍存在 | [ ] |
| 13 | 再次收藏同一资源 | 不新增重复记录；界面提示资源已在书架中 | [ ] |
| 14 | 从书架移除该资源并刷新 | 资源消失，且不会重新出现 | [ ] |

## 权限与接口

| 步骤 | 操作 | 预期结果 | 结果 |
| --- | --- | --- | --- |
| 15 | 账号 A 收藏一条资源后切换至账号 B | 账号 B 的书架不显示账号 A 的收藏 | [ ] |
| 16 | 使用账号 B 的访问令牌请求删除账号 A 的资源 ID | 不会删除账号 A 的收藏；账号 A 刷新后仍可见 | [ ] |
| 17 | 未带 Authorization 请求 `GET /api/saved-resources` | 返回 401、`UNAUTHORIZED` 和统一 JSON 信封 | [ ] |
| 18 | 访问 `/api/health` | 返回 200，且 `data.supabase` 为 `connected` | [ ] |
